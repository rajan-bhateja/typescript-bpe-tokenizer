# Thoughts

## On the IDE

* Love that it's a fork of VS Code so, that makes it very familiar.

* Everything is working as expected - no issues.

* A UI annoyance I've noticed is that when you go to select an option from multiple options, usually in `Settings`, the options' values aren't centered in their rows, they're slighly up in their area.
    * For example, when you go to change the theme of the IDE, the options you see aren't centered in their area, they'll be slightly top aligned.


## On TokenFold

* I don't know how it works, but it definitely works.

* Token usage was noticably lower compared to your usual AI IDEs like Cursor or AntiGravity.

* A small problem I noticed while using the `Chat` option (`Ctrl` + `Alt` + `I`) is that sometimes, the model is too literal with the generation.

    * For example, if I asked the model to replace the placeholder value with `something like this`, it'll take that exact `something like this` as replacement value instead of generating a 'better' one.

* I would also like to have the option that whenever I open the `Chat` tab, it opens straight to my last conversation. (It's a Preference option, I know, but that's just my opinion.)
